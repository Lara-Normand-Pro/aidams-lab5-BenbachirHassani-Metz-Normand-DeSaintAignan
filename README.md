# AIDAMS Lab 5: Put uncertainty into your project

IDSI 51003 Research and Emerging Topics in Data Science: Climate Risks
Group: Lara Normand, Amine Benbachir Hassani, Camille Metz, Tiphaine De Saint Aignan
Role: Climate risk analyst. Project: Aviation allowance exposure

Key quantity: 2026 EU ETS carbon cost of 11 European airline groups, in % of revenue.

## Files
- `lab5.ipynb`: the lab notebook (Parts A to F, answers Q1 to Q7)
- `data/ets_by_group.csv`: verified EU ETS emissions per airline group, 2012 to 2025 (EU Union Registry)
- `data/airline_financials.csv`: revenue, EBIT and Scope 1 CO2 per group, with sources
- `figures/fig_uncertainty.png`: fan chart for the paper

## Run
Open `lab5.ipynb` and run Kernel > Restart & Run All (needs pandas, numpy, scipy, matplotlib).
